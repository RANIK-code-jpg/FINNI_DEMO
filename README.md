# FINNI DEMO 🦕

### Демонстрационная версия мобильного приложения «Питомец Финни»

**FINNI** — мобильное приложение на Flutter, предназначенное для знакомства детей 7–11 лет с основами финансовой грамотности через взаимодействие с виртуальным питомцем-динозавром.

Данная версия предназначена для демонстрации игровых механик и образовательных возможностей приложения.

## 🎯 Цель проекта

Помочь детям освоить базовые принципы управления личными финансами в игровой форме: выполнять задания, получать игровые монеты, распределять бюджет, копить на цели и заботиться о виртуальном питомце.

## 🦕 Возможности демоверсии

* **Виртуальный питомец:** взаимодействие с динозавром и отслеживание его состояния.
* **Игровая экономика:** работа с балансом и игровыми монетами.
* **Задания:** демонстрация заданий и механик их выполнения.
* **Финансовая грамотность:** знакомство с бюджетированием, накоплениями и финансовыми целями.
* **Демонстрация уровней:** возможность показать разные этапы игрового прогресса.
* **Расширенные возможности демонстрации:** увеличенный запас игровых монет и доступ к игровым механикам, предусмотренным демоверсией.

> Демоверсия предназначена для презентации функциональности приложения. Игровые параметры могут отличаться от основной версии.

## 🛠️ Технологии

* **Flutter** — разработка пользовательского интерфейса и приложения.
* **Dart** — основной язык программирования.

## 📂 Структура проекта

Основные каталоги проекта:

* `lib/` — исходный код приложения.
* `lib/screens/` — экраны приложения.
* `lib/services/` — игровые состояния и логика приложения.
* `android/` — конфигурация Android-приложения.
* `assets/` — графические и другие ресурсы проекта, если они используются.
* `pubspec.yaml` — зависимости и настройки Flutter-проекта.

## 🚀 Запуск проекта

Для запуска необходимы установленный Flutter SDK и Android SDK.

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/RANIK-code-jpg/FINNI_DEMO.git
   ```

2. Перейдите в каталог проекта:

   ```bash
   cd FINNI_DEMO
   ```

3. Установите зависимости:

   ```bash
   flutter pub get
   ```

4. Проверьте окружение:

   ```bash
   flutter doctor
   ```

5. Запустите приложение на подключённом устройстве или эмуляторе:

   ```bash
   flutter run
   ```

## 📦 Сборка APK

Для создания релизной APK-сборки выполните:

```bash
flutter build apk --release
```

Готовый APK-файл будет находиться по пути:

```text
build/app/outputs/flutter-apk/app-release.apk
```

Перед распространением APK необходимо проверить работоспособность приложения на целевом Android-устройстве.

## 🔒 Безопасность и ограничения

FINNI — игровой образовательный проект. Игровые монеты являются виртуальными и не представляют реальную денежную стоимость.

Демоверсия предназначена для демонстрации приложения и не должна рассматриваться как полноценный финансовый сервис. Фактические возможности зависят от реализации текущей версии.
